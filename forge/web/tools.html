2 · Right-click “Read Aloud” on any site

    

      On a GitHub repo page, “whole page” reads the README — not the
      file list, the sidebar or the footer. “From here” starts at the paragraph you
      clicked and runs to the end.
    

    

      That needs the Firefox add-on in extension/. It cannot be installed
      from this page (Firefox only installs signed add-ons from files), but it is four clicks:
    

    
    
      
  1. Type about:debugging#/runtime/this-firefox in the address bar.
    2. 
      
  2. Click Load Temporary Add-on….
    3. 
      
  3. Open C:\Users\l3ung\forge\extension\ and pick manifest.json.
    4. 
      
  4. Now select text on any page → right-click → Read Aloud,
          or right-click a paragraph → Read Aloud — from here,
          or Read Aloud — whole page.
    5. 
    

    

      Temporary means it disappears when Firefox restarts — the add-on is also on your
      toolbar (speech-bubble icon) and supports
      Alt+Shift+R on the selection,
      Alt+Shift+P pause, Alt+Shift+S stop.
      To make it permanent, sign it once at addons.mozilla.org — see docs/FIREFOX.md.
